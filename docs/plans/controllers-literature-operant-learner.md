# Literature review for spec 3.2 (operant learner), 2.5 (candidate set) and 2.6 (combination rule)

Scope: read-only. No files changed. Sources I read in full text are marked [read]; those I could only confirm from abstracts or secondary summaries are marked [abstract]; anything from my own recollection of a paper is marked [recalled] and should be checked before it goes in the paper. Inference on my part is marked [inference].

**Terms used below.** *Posterior mean/variance*: the running estimate of a quantity and how unsure the learner is about that estimate. *Kalman filter*: a running average whose step size is set by that uncertainty (large step when unsure, small when sure) and which assumes the true quantity drifts over time, so uncertainty creeps back up when nothing is observed. *Process noise* (tau squared): the assumed size of that drift per step. *Precision*: 1/variance. *Softmax*: turning a set of scores into choice probabilities that sum to 1. *Devaluation*: the outcome an action produces becomes worthless or aversive; a *goal-directed* system stops the action at once, a *habit* keeps going. *Thompson draw*: pick the action whose random sample (mean plus noise scaled by its SE) is largest. *Option*: a temporally extended action ("go to X") that ends in a state where primitive actions apply.

**What this establishes.** Only the Kalman family and Bayesian Q-learning give both the value and the uncertainty in the common unit, which spec 2.1 requires. Policy-form models (actor, Bush-Mosteller) keep the legacy intention and the competition exactly, but cannot report V(K|H) with an SE, and the actor drifts toward habit. The current `OperantEstimator` is already a moment-matched Bayesian Q-learner; the p117 failure was not the model class but the prior scale (SE 1 against values of about 0.17, the mean EAT-food engram value) and the mismatch between stop rule and draw.

## 2. Recommendation for spec 3.2: a per-cell Kalman filter with a pooled prior and abstention

**State per cell (object type o, action a).** `m` = posterior mean of the drive reduction; `P` = posterior variance of that mean (SE squared); `s2` = running estimate of outcome spread (sigma squared, exponentially weighted Welford as now).

**Update on an outcome v (one update per `Valuation` event, as decided):**
```
P  <- P + tau2                      (predict: the world may have drifted)
k  <- P / (P + s2)                  (gain; s2 floored at s2_min)
m  <- m + k * (v - m)               (good outcome raises m, bad lowers it)
P  <- (1 - k) * P                   (less unsure after seeing an outcome)
s2 <- Welford update with v         (spread of single outcomes)
report: Q = m, SE = sqrt(P), sigma = sqrt(s2)
```
**Between outcomes:** for every other action on the same object, when that object yields an outcome by any action, `P <- P + tau2`. This is DKM's drift term applied to cells that were not observed. (The clock is a question for the researcher; see section 5.)

**Replaces:** Q0 = 0, SE 1, and the 0.995 count decay. The decay was an ad hoc forgetting (Dearden's own words); tau2 is the principled form, and it sets the steady-state gain `k* = (sqrt(tau2^2 + 4 tau2 s2) - tau2) / (2 s2)`. Pick tau2 so that k* is about 0.2-0.3 (recent outcomes dominate, spec "fast"), then let the calibration test (spec 2.4) correct it: z-variance above 1 means tau2 too small.

**Prior for an untried cell (spec 2.2).** Hierarchical shrinkage ([Gershman & Niv 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4537661) [abstract]): if the action `a` has outcomes on other objects, `m0 = pooled mean of a across objects`, `P0 = pooled between-object variance of a + tau2`, `s2_0 = pooled s2`. This is honest: it claims what the creature actually knows about eating in general, not about this object. If the action has never been tried on anything, the cell **abstains** (SE = infinity; weight 0 in the combination rule below, and excluded from the operant's own draw). No lottery ticket.

**Competition between actions on one object (the open principle).** The literature does not support lowering the *value* or raising the *uncertainty* of alternatives because one action proved good. Explaining away in the Kalman filter happens only when predictors are present together and share one outcome ("the prediction error is divided out among all the stimuli that are present", DKM Box 1); mutually exclusive actions never share an outcome, so evidence that EAT pays says nothing, in drive units, about whether OBSERVE pays. Relative-value learning does implement the principle, but it leaves the common unit and is documented as a source of irrational choice. What the literature does support is competition **at the choice**: softmax over values (Daw 2005), divisive normalisation of value by the sum over alternatives ([Louie, Khaw & Glimcher 2013](https://www.cns.nyu.edu/~klouie/papers/pubLouieGrattanGlimcher.html) [abstract]; the form R_i = V_i / (sigma_H + omega sum_j V_j) is [recalled]), and the Thompson draw already in the arbiter. There, a confident high value does shrink the alternatives' share, which is the legacy's sum-to-1 row realised as choice probability rather than as stored estimates. So: represent the principle in the draw, not in the cells. And be candid about the opposite effect: the drift term makes untried alternatives *more* likely to be sampled over time. That is deliberate exploration and it is correct when SE is on the outcome scale (0.1-0.2), where it was ruinous only at SE 1. The report's own finding that the win rate followed Phi(0.85)^(n-1) is a scale-and-count problem, and the many-arm bandit literature confirms that trying every arm once already costs regret of order k ([Bayati et al.](https://arxiv.org/pdf/2002.10121v3) [abstract]).

## 3. Spec 2.5 (candidate set) and 2.6 (combination rule)

**2.5: two stages, not a flat list.** Daw 2005 arbitrates over the few actions available *at a state*; Lee, Shimojo & O'Doherty 2014 use one model-based weight per state ([abstract](https://pmc.ncbi.nlm.nih.gov/articles/PMC3968946); the P_MB dynamics with reliability-dependent transition rates and Q = P_MB Q_MB + (1-P_MB) Q_MF are [recalled]); Keramati et al. 2011 compute the value of information per action at a state ([read, PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC3102758)). None arbitrates over a flat product of targets and actions. "Go to object X" is an option in Sutton, Precup & Singh's sense and Botvinick, Niv & Barto 2009 map that hierarchy onto the brain [abstracts]; Mapa's split (memory picks the object, the table picks the action) is the same two-level structure. Recommendation: stage 1 chooses the focal object (episodic memory, innate tendencies, later the JEPA; the operant abstains, which is option (a) made operational); stage 2 chooses the action on that object (operant and episodic). This cuts the draw from 10-30 to 3-5 candidates per stage, which alone removes most of the measured failure, and it gives "operant at the object" a precise meaning.

**2.6: precision-weighted mixture per candidate, with a VPI-style gate on cost.** Daw 2005 picks per (state, action) the controller with the lower variance and notes that "softer integration schemes, such as a certainty-weighted average, are also possible" [read]. Given calibrated SEs in one unit (spec 2.4 is exactly the licence for this), the Bayesian combination is `Q = (Q1/SE1^2 + Q2/SE2^2) / (1/SE1^2 + 1/SE2^2)`, `1/SE^2 = 1/SE1^2 + 1/SE2^2`. Abstention (SE infinite) drops out automatically, which the hard-choice rule cannot do. Whether to pay for the expensive controller is Keramati's question: consult episodic memory when the value of perfect information of the operant's best action exceeds the cost (their rule, Dearden's VPI, which measures the overlap of the best and second-best distributions). The current stop rule is a crude version of that; its defect is that decisiveness compares two candidates while the draw runs over all. Fix: decisiveness = probability that the best candidate wins the whole draw (Monte Carlo or the product of pairwise Phi as the report suggests), and only then stop. Cross-controller comparability rests on the common unit plus per-controller calibration; nothing else makes a kNN SE and a Kalman SE comparable.

## 4. Predictions in the phased experiment (spec 4)

Two kinds of "devaluation" must be distinguished, because they test different things (Daw 2005 separates devaluation from contingency change):

- **Need change** (creature sated, food's drive reduction drops): a learner that stores a scalar V at outcome time (the Kalman cell above) keeps recommending EAT until it re-experiences the outcome, then adapts in 2-4 bites at k* about 0.3. Episodic memory stores the drive-change vector G and values it against H_now, so it adapts with no re-experience. This is the goal-directed versus cached signature, and arbitration should shift trust to episodic at the change. If the operant also stored a drive-change vector and valued at retrieval, it would match episodic here and the phase would not separate them.
- **World reversal** (a food type becomes worthless or painful): the Kalman cell adapts in a few bites; kNN episodic memory is slow because old engrams persist until outnumbered. Here arbitration should shift trust to the operant, and A5's fixed order should lose. Approach credit (stage 1) remains episodic-only in every phase, provided the timeout rule in 3.3 is fixed.
- The actor/Bush-Mosteller alternatives would predict persistence in both phases (habit), which is why they are excluded. Plain Bayesian Q-learning with the 0.995 decay predicts the same as the Kalman cell but with less principled speed.

Prediction for the stable phase: both arms survive if the innate filter is on; with a 3-5 candidate stage-2 draw at outcome-scale SE, the operant should eat offered food in well over half of its decisive decisions rather than 7.6%.

## 5. What remains uncertain; questions for the researcher

1. **Which devaluation?** Need change tests whether controllers value at retrieval; world reversal tests speed of relearning. They favour different controllers. I recommend running both as separate phases or arms; pre-register which one the arbitration claim rests on.
2. **Scalar or vector in the operant cell?** Storing the drive-change vector makes the operant need-sensitive (good against the "not a habit" clause) but erases the need-change contrast with episodic memory. Decide before pre-registration.
3. **Clock for tau2 on unobserved cells:** per decision cycle, per visit to the object, or per outcome on that object by any action? I proposed the last; it is the least arbitrary but is my inference, not from the literature.
4. **Is a pooled across-object prior "evidence" under spec 2.2?** I argue yes (it is knowledge about the action), but it should be recorded in the decision table so calibration can be checked separately for pooled-prior cells.
5. **Abstention changes the `Estimate` contract** (SE = infinity) and the arbiter's draw; the precision mixture handles it, the current first-decisive rule does not.
6. **Stage 1 in the A2 arm:** if only episodic memory and the innate tendencies answer "which object", the operant-only arm has no learner at stage 1. State this in the arm descriptions, or let the pooled action prior act as a weak stage-1 prior.
7. Unverified in primary text: Lee 2014's exact weight dynamics, the Louie/Glimcher normalisation equation, Behrens's model details. Check before citing them in the paper.
